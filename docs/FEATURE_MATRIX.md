# مصفوفة الميزات — الحالة المحلية

آخر مراجعة: 2026-11-22. تفرق هذه المصفوفة بين وجود الكود، وبنائه، والتحقق من سلوكه على الهاتف. لا تعتبر الواجهة أو نجاح البناء دليلًا على اكتمال ميزة.

| المجال | الحالة الحالية | الدليل والحد |
|---|---|---|
| بنية .NET 8 | مبنية | `dotnet build CrossPlatformDataTransfer.sln --no-restore` نجح دون أخطاء أو تحذيرات في آخر بناء مسجل |
| اختبارات حدود الأمان | 6 اختبارات ناجحة | اختبارات الوحدة لا تثبت تكامل TLS أو نقل الملفات على Android |
| واجهة Windows WPF | معاينة تطويرية | واجهة RTL عربية، اكتشاف عند الفتح، وشرح منفصل لرمز الاقتران وبصمة TLS؛ لا تعرض تدفق نقل ملفات |
| حزمة Windows | معاينة محلية | موجودة في `outputs/CrossPlatformDataTransfer-Windows-Dashboard-Preview`؛ ليست مثبتًا إنتاجيًا ولا موقعة بشهادة ناشر |
| اكتشاف ADB | جزئي ومشاهد على A13 | `SM-A135F` ظهر بعد إعادة توصيل USB. لا تُعد القائمة وحدها دليلًا على عمل Agent |
| اختيار ADB | محسّن محليًا | يفضل Android SDK Platform-Tools بدل `C:\Windows\adb.exe` القديم؛ أوامر الخدمة محدودة بالاكتشاف ومعلومات الجهاز وتمرير المنفذ |
| Android Agent | نموذج Kotlin أولي مبني | APK Debug موجود ومثبت على هاتف المالك SM-A135F، Android API 34؛ لا تثبيت أو تجربة على هاتف آخر |
| TLS على Android/Windows | الكود بُني وثُبّت، لكن القبول الميداني غير ناجح | آخر محاولة على A13 فشلت لأن خدمة Agent كانت متوقفة؛ لم نرَ مصافحة ناجحة أو تحققًا من رفض بصمة مختلفة |
| أوامر Agent | اقتران ومعلومات عامة فقط | `PAIR`, `PING`, `HANDSHAKE`, `GET_CAPABILITIES`؛ قدرات القراءة والكتابة فارغة |
| نقل Android إلى Windows | غير منفذ | لا منتقي ملفات Android ولا رسائل chunks/ACK ولا حفظ مؤقت مع تحقق نهائي |
| نقل Windows إلى Android | غير منفذ | لا اختيار ملف على Windows ولا `ACTION_CREATE_DOCUMENT` أو وجهة آمنة |
| SHA-256 للنقل | ليس جزءًا من نقل عامل | وجود خدمات hash في Core لا يثبت تحقق ملف متلقٍ |
| النسخ الاحتياطي والاستعادة | غير منفذ | لا حاوية نسخة أو manifest أو معاينة استعادة أو تقرير لكل عنصر |
| الصور والفيديو والملفات | غير منفذ كوحدات منتج | يجب بناءها عبر SAF أو Photo Picker وباختيار المستخدم |
| جهات الاتصال | غير منفذ | لا مزود Android أو طلب إذن أو استيراد/استعادة مختبر |
| SMS وسجل المكالمات | معطل/غير منفذ | المسار السابق المعتمد على root أزيل؛ أي تنفيذ مستقبلي يحتاج تقييم أذونات Android والسياسات والقيود قبل الوعد به |
| بيانات التطبيقات الخاصة | غير متاحة كميزة عامة | لا ادعاء بنسخ قواعد بيانات التطبيقات الأخرى أو تجاوز sandbox |
| iOS | غير منفذ ويحتاج دراسة | لا تطبيق iOS أو تدفق مدعوم مثبت |
| خادم TCP القديم وCLI | معطلان | أزيل مستمع TCP غير المشفر؛ CLI يوضح أنه غير مدعوم ولا يبدأ خادمًا |
| الترخيص والتحديثات | غير مفعّلة | لا backend ترخيص موثوق ولا endpoint تحديث موقّع؛ التنفيذ يفشل مغلقًا |
| إصدار تجاري | غير جاهز | لا مفاتيح توقيع إنتاجية أو installer نهائي أو مصفوفة توافق أو مراجعة أمنية مستقلة |

## تعريف الحالة

- **موجود:** توجد شيفرة أو واجهة فقط.
- **مبني:** أداة البناء أنهت بنجاح.
- **مجرّب محليًا:** سلوك محدد شوهد على بيئة المطور.
- **متحقق على جهاز:** اختبر السيناريو كاملًا على الجهاز المقصود مع أدلة ونتيجة قابلة للتكرار.
- **جاهز للإصدار:** اجتاز بوابات الأمان والموثوقية والتوافق والتوقيع والتوثيق. لا يوجد مجال بيانات مصنف بهذه الحالة حاليًا.
