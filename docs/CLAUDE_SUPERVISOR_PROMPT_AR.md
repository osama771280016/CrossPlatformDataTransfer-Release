## استخدام Claude Desktop بأقل صلاحية

1. افتح Claude Code/العمل البرمجي واختر مجلد المستودع أعلاه وحده، لا مجلد `Documents` كاملًا ولا القرص `C:` كله.
2. ابدأ بالمراجعة فقط. ارفض أي طلب لفتح مجلد الهاتف الشخصي أو صور المستخدم أو ملفات الاعتماد.
3. إذا ظهر اختيار السماح للقراءة أو التعديل، ابدأ بالقراءة. لا تعطِ صلاحية الكتابة إلا في جلسة تنفيذ مرحلة متفق عليها، وبعد إنشاء commit احتياطي أو فرع.
4. ربط GitHub ليس لازمًا للمراجعة المحلية إذا كان المجلد المحلي مفتوحًا. إن احتجنا الربط لاحقًا، اختَر المستودع المحدد فقط وأقل أذونات قراءة تكفي؛ لا تمنح كل المستودعات أو صلاحية إدارة الحساب. أي صلاحية OAuth يوافق عليها المالك بنفسه بعد رؤية نطاقها.
5. لا تضف خادم MCP أو إضافة غير معروفة الآن. كل تكامل يوسع سطح الوصول ويجب تبرير حاجته قبل تثبيته.
6. راجع حدود الاستخدام من صفحة حساب Claude. إذا انتهت الحصة، لا تفتح حسابًا بديلًا للتحايل؛ استأنف بعد التجدد أو أكمل بمراجعة محلية مجانية.
