# TransferAI Android Agent

هيكل أولي لوكيل Android مكتوب بـKotlin. هذه المرحلة مخصصة لاختبار قناة TLS والاقتران عبر USB/ADB فقط؛ لا توجد أوامر لقراءة بيانات الهاتف أو تغييرها. تحديث TLS بُني، لكنه يحتاج إعادة تثبيت وتجربة على الهاتف قبل اعتماده.

## ما يفعله هذا الإصدار

- يبدأ المستخدم خدمة ظاهرة بإشعار مستمر.
- يستمع التطبيق إلى `127.0.0.1:4711` فقط، ثم يصل Windows إليه عبر `adb forward`.
- ينشئ شهادة جلسة EC مؤقتة في Android Keystore، ويعرض رمز تحقق بصمتها لمقارنته مع الرمز في Windows.
- لا يرسل رمز الاقتران المؤقت من 8 أرقام قبل تأكيد تطابق رمز TLS على الهاتف وWindows. لا تحفظ مفاتيح الجلسة بعد انتهاء التشغيل.
- يفرض أمر `PAIR` أولًا لكل اتصال ويغلق الاتصال بعد خمس محاولات رمز خاطئ.
- بعد الاقتران يقبل `PING` و`HANDSHAKE` و`GET_CAPABILITIES` فقط.
- يستخدم TLS 1.2 على الأقل؛ داخل TLS تظل رسائل التطبيق مؤطرة بطول Big Endian.
- يعلن أن قائمتي القراءة والكتابة فارغتان؛ النقل الحقيقي غير مفعّل.

## الأدوات اللازمة للبناء

- Android Studio مع Android SDK Platform 36 وPlatform-Tools.
- JDK 17 أو JDK المرفق مع Android Studio.
- اتصال إنترنت عند أول مزامنة Gradle لتنزيل Android Gradle Plugin وKotlin Gradle Plugin.

افتح مجلد `android-agent` في Android Studio ووافق على مزامنة Gradle، ثم اختر **Build > Build APK(s)**. أو من PowerShell داخل المجلد شغّل `.\gradlew.bat assembleDebug`. يستخدم المشروع Gradle Wrapper 8.13، مع التحقق من بصمة ملف Gradle قبل تشغيله.

## اتصال USB التجريبي

1. ثبّت APK وافتح التطبيق على الهاتف.
2. اضغط «بدء الاتصال» واسمح بإشعار الخدمة، ثم اترك الخدمة نشطة.
3. فعّل USB debugging ووصل الهاتف بالكمبيوتر ووافق على رسالة الثقة.
4. افتح واجهة Windows واتصل بالهاتف؛ ستظهر بصمة TLS في الطرفين.
5. قارن الرمز يدويًا. إذا تطابق، اضغط تأكيدًا على الهاتف ثم زر إكمال الاقتران في Windows.
6. يرسل Windows رمز الاقتران داخل TLS، وبعد نجاحه يمكن إرسال `HANDSHAKE` و`PING` و`GET_CAPABILITIES`.

كل إطار هو 4 بايت لطول الحمولة بترتيب Big Endian، ثم JSON UTF-8. الحد الأقصى للإطار 1 MiB. حقول الطلب هي `commandType` و`parameters`، وحقول الرد `success` و`message` و`data`.

## ما لم يُنجز بعد

- إعادة تثبيت هذا التحديث واختبار TLS وتطابق الرمز على هاتف فعلي.
- نقل ملفات/صور باستخدام واجهات Android الرسمية والتحقق من SHA-256.
- الاختبار على هاتف فعلي، ثم إضافة أنواع بيانات وأذوناتها واحدة تلو الأخرى.
- التحقق من حدود مهلة خدمة `dataSync` على إصدارات Android المستهدفة.
