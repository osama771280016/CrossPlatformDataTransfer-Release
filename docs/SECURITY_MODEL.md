# نموذج الأمان لنقل الملفات

## الحالة التنفيذية

- يتطلب الاتصال تفعيل USB debugging وتفويض هذا الكمبيوتر من نافذة Android الرسمية. اختر المستخدم جهازًا واحدًا للاختبار: Samsung SM-A135F (A13، Android API 34). لا يُستخدم أي هاتف آخر.
- يستمع Android Agent إلى `127.0.0.1:4711` فقط، ويُنشأ تمرير ADB للهاتف المحدد. اختير Android SDK Platform-Tools لتجنب تعارض نسخ ADB المختلفة على Windows.
- بعد التحديث الحالي، يستخدم الطرفان TLS 1.2 أو أحدث. ينشئ Android شهادة EC مؤقتة باستخدام Android Keystore. يعرض الطرفان بصمة SHA-256 للشهادة في صيغة 5-5 أحرف سداسية عشرية، ويجب أن يقارنها المستخدم ويؤكد التطابق على الهاتف قبل إرسال رمز الاقتران عبر TLS.
- تثبيت نسخة TLS الحالية على A13 نجح. لم يُكمل المستخدم بعد تأكيد البصمة والاقتران في الجلسة الحالية؛ لذلك لا نعد تحقق الاتصال الآمن الجديد ناجحًا حتى ذلك الاختبار.
- محاولة الاتصال الأخيرة لم تجد خدمة الوكيل العاملة. ظهر A13 مجددًا بعد إعادة توصيل USB، لكن خدمة الوكيل وتمريرة المنفذ 4711 غير نشطتين. لا تُرسل بيانات قبل بدء الخدمة واجتياز خطوة التأكيد على الطرفين.
- البروتوكول يتيح `PAIR` و`PING` و`HANDSHAKE` و`GET_CAPABILITIES` فقط. نقل الملفات والرسائل وجهات الاتصال والنسخ الاحتياطي غير متاح.
- أزيلت واجهة ADB للأوامر التعسفية وعمليات root والنسخ المباشر من/إلى مسارات Android. كما أزيل خادم TCP القديم غير المشفر ووضع CLI الذي كان يشغله.

## حدود الثقة

- تفويض ADB يمنح هذا الكمبيوتر الموثوق قدرة تصحيح Android؛ لا توافق على تفويض كمبيوتر غير موثوق، ويمكن إلغاء التفويض من إعدادات المطور في الهاتف.
- قصر المنفذ على loopback يمنع الوكيل من الاستماع مباشرة على شبكة Wi-Fi، لكنه لا يحمي من برنامج خبيث يعمل على الكمبيوتر الموثوق أو من مضيف ADB مخترق.
- رمز المقارنة يثبت أن الطرفين يعرضان بصمة الشهادة نفسها عند المقارنة البشرية؛ اختلافه يعني الإلغاء الفوري. رمز الاقتران قصير العمر ولا يُحفظ عمدًا.
- شهادة الجلسة مؤقتة، ويُحذف المفتاح عند إيقاف الوكيل. لا توجد ثقة مستمرة بين التشغيلات.

## قواعد قبل نقل أي بيانات

1. لا تُفتح أوامر بيانات جديدة قبل اكتمال اختبار الاتصال TLS على A13، بما يشمل حالة قبول البصمة الصحيحة ورفض اختلافها.
2. بعد موافقة المستخدم على البصمة في الهاتف، يرسل Windows رمز الاقتران المؤقت داخل TLS. تُرفض الجلسة عند انتهاء الرمز أو خطئه.
3. تبقى حدود أحجام الإطارات والمهل والإلغاء قائمة فوق TLS. تُرفض الأوامر غير المعلنة، وينهي الانقطاع أو فشل TLS الجلسة.
4. أول قدرة ملفات مخطط لها: Android إلى Windows، ملف واحد يختاره المستخدم من منتقي النظام عبر Storage Access Framework (`ACTION_OPEN_DOCUMENT`) دون إذن تخزين شامل.
5. يعرض Windows بيانات الملف، ويطلب بدء النقل، ثم يتيح للمستخدم اختيار وجهة الحفظ. يستخدم النقل ملفًا مؤقتًا، ويتحقق من الحجم وSHA-256 قبل اعتماد النتيجة.
6. لا يُستخدم اسم الملف القادم من الهاتف كمسار. لا يُستبدل ملف موجود دون اختيار صريح، ولا يُعلن النجاح بعد إلغاء أو فشل التحقق.

## السجلات والخصوصية

- لا تُسجل رموز الاقتران أو رمز التحقق أو المفاتيح أو محتوى الملفات أو المسارات الخاصة.
- لا تُرسل بيانات إلى الإنترنت أو خدمة خارجية في مراحل USB المحلية.
- لا root ولا `MANAGE_EXTERNAL_STORAGE` ولا قراءة قواعد بيانات تطبيقات أخرى. تُطلب أذونات Android الرسمية وقت الحاجة مع بيان غرضها.
